# Isometric Tiles — 菱形地图视图

Isometric Tiles 以一定角度绘制图块地图，呈 2:1 的菱形网格，让建筑和树木从地面里"立"起来。它是共享引擎 Tile Rendering 的两种地图视图之一；另一种是 Top-down Tiles。同一批地图、事件和存档在两种视图下都能使用。

![等距视角下的正午 RPG Plus 村庄：广场、路灯、房屋、村民和走在小路上的主角；地图边缘之外是空的背景。](assets/village-isometric.jpg)

## 与俯视视图的不同

- **菱形格子。** 每格画成一个宽是高两倍的菱形。逻辑网格仍是方的：一格的四个邻居和原来相同。
- **立起来的物件。** 图块集标记出的建筑等多格物件，会画成竖立的图像或若干个平面，而不是平铺的图块。
- **角色**会根据自己在菱形网格上的朝向挑选对应的精灵行。
- **点击**地图时选中指针下的菱形；RPG 地图编辑器使用同样的规则。

![同一张村庄地图的两种视图：左边俯视，右边等距。](assets/same-map-two-projections.jpg)

不变的是：行走规则、碰撞、事件、战斗、存档、光照和昼夜都归 RPG 模组和 Tile Rendering 所有，在两种视图中的表现完全一致。

## 局限

- **按键跟随网格，而不是屏幕。** 上和下（W/S、方向键）沿屏幕的一条对角线移动，左和右沿另一条，因为它们是在方格网格上把主角移动一格。
- **地图边缘会露出来。** 靠近地图角落时，能看到菱形边界之外的空背景，如上图所示。
- **图块集需要预先准备。** 只有当图块集把物件描述成组合时，它们看起来才是立着的；普通图块平铺在菱形上。

## 如何启用

在游戏的方案（**模组与合集 → 合集 → 对应游戏 → 编辑结构**）中加入这个模组，并把**地图投影**设为**等距**。设置 `tile.renderer` 的值为 `isometric`：

```json
"settings": { "tile.renderer": "isometric" }
```

不想改游戏、只想试一次的话，在命令行用 `--tile-renderer=isometric` 启动。RPG Plus 已经包含两个渲染器，所以只需改设置。

## 如果遇到问题

1. **地图是空的。** 游戏的**地图投影**要求一个未包含的渲染器；请加入这个模组，或选择其他投影。
2. **主角斜着走。** 这种视图下按键就是这样工作的（见"局限"）。
